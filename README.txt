ORVANTA CASE REVIEW — STATIC DEMONSTRATION

Run: extract the ZIP and open index.html in a browser. Keep styles.css and
script.js beside it. No build, libraries, account, or internet connection needed.
Optional development server (Python 3):
  python3 -m http.server 8000 --directory /workspace/conlsut

The form deliberately cannot deliver requests. Use fictional details only.
Its required fields use browser validation, then show the requested error.
With JavaScript disabled, form fields remain disabled. No payments or uploads.
